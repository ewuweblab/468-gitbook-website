## Challenges

[GitHub - ewuweblab/google-doodle-template: Google Doodle TemplateGitHub](https://github.com/ewuweblab/google-doodle-template)

#### Challenge 1: Content <a href="#challenge-1-content" id="challenge-1-content"></a>

* Determine an engaging topic for Google.com
  * See https://doodles.google/
* Use `SVG` as code
* Export and optimize your SVG files
  * ​[Reference Export and Optimize an SVG](https://www.linkedin.com/learning/learning-javascript-animations-with-greensock/export-and-optimize-an-svg)​

#### Challenge 2: Design <a href="#challenge-2-design" id="challenge-2-design"></a>

* Determine _Art Direction_ supporting your-topic
* Pick fixed-width and fixed-height dimensions for your design
* Create an `SVG` illustration for your topic in your preferred vector design tool
* Design multiple engaging elements ready for animation

#### Challenge 3: Code <a href="#challenge-3-code" id="challenge-3-code"></a>

[GitHub - ewuweblab/google-doodle-template: Google Doodle TemplateGitHub](https://github.com/ewuweblab/google-doodle-template)

* Use provided template
* Use GSAP or Greensock Animation Platform to animate it
* Use one or more GSAP plugins

#### Challenge 4: Process <a href="#challenge-4-process" id="challenge-4-process"></a>

* Fork the provide Google Doodle template
* Apply Art Direction
* _Version Control_ is used with multiple commits, over multiple days
* Project is stored on GitHub
* Project is deployed via Netlify
  * Add a deployment link to your repo
* Add deployment URL to _**About**_ section -> _**Website**_ field

#### Challenge 5: Deployment <a href="#challenge-5-deployment" id="challenge-5-deployment"></a>

* Provide URL to your project _repo_ stored on _GitHub_
  * Example: _https://github.com/**YourUserName**/**RepoName**_
* Provide URL to your project website deployed via _Netflify_
  * Example: https://**YourAppName**.netlify.com
